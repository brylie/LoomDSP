# Design Specifications

Living specifications: how a feature works in detail. Modules and their ports, rules and their reasons, worked examples, and open points.

Specifications change as the work teaches us. Edit them in the same pull request as the code they describe. The decision behind each one is recorded in an [ADR](../adr/README.md), which does not change.
