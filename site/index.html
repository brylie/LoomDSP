LoomDSP is a free, open-source modular synthesizer and sound lab. Build instruments and effects by connecting small modules on a canvas. Hear every change as you make it. Then play the result with a MIDI keyboard.

Download View on GitHub

Who it is for

  • Live performers

    Play patches on stage with your MIDI controllers. Change them while they sound.

  • Sound designers

    Build a sound from the smallest parts. Try odd ideas fast and keep the ones you like.

  • Modular fans

    Patch anything to anything, with real feedback loops, and no rack to buy.

  • Curious learners

    Every module explains itself on hover. Short guides explain the ideas behind the sound.

What makes it different

  • Edit while it plays. Add, remove, and rewire modules during a performance with no dropouts.
  • Patch anything to anything. Audio can shape a filter, and an envelope can drive pitch. Colours guide you but never block a cable.
  • Real feedback loops. Patch an oscillator back into itself and it sounds right, one sample at a time.
  • The same sound every time. A patch gives identical audio on every run, at any buffer size.
  • Safe for your ears. A limiter and a short fade-in sit before the output, so a wild patch never blasts you.
  • Fast and native. Drawn on the GPU. No web view, no Electron.
  • Open all the way down. Apache-2.0 code. Patches are plain text files that never run code, and the patches you make are yours.

Download

LoomDSP is in early alpha. It is not a finished instrument yet, and patches may stop loading between versions.

Get the latest release

Pick the file for your system on the release page. If there is no download for your system yet, build it from source:

git clone https://github.com/brylie/LoomDSP
cd LoomDSP
cargo run --release -p loom-app -- examples/patches/subtractive.ron

You need Rust 1.99 or newer. On Linux, also install the ALSA development package (libasound2-dev on Debian and Ubuntu). The first build takes a few minutes.
